## Platform Overview

The TI Planning Tool has the following principal views:
* a [Landing Page](/docs/platform_introduction/overview.md), which currently serves primarily for user authentication
* a [Dashboard](/docs/platform_introduction/dashboard.md) that provides an overview of a user's studies (plans) and permits to launch the creation of a [new plan](/docs/plan/create_new_plan.md)
* an overview of the user's [Data](/docs/platform_introduction/data.md) within the Studies
* the workflow-based planning process for the personalized and non-personalized [TI modes](/docs/background/modes.md) — see [Workflows](/docs/plan/workflows.md) for a full overview

  Personalized workflow steps:

  * [Offline Personalization](/docs/services/data_privacy.md) *(optional — for privacy-sensitive workflows)*
  * [File Picker](/docs/services/file_picker.md)
  * [Personalizer](/docs/services/personalizer.md)
  * [Model Inspector](/docs/services/fiducials_placement.md)
  * [Simulator](/docs/services/simulator.md)

  Available in all plan types:

  * [TI Analysis](/docs/services/post_processing.md)
  * [Exposure Analysis](/docs/services/s4l_post_processing.md)
